# GEES (Gestion Efficace des Établissement Scolaires)

 # Membre du groupe
 - Joriel JOSEPH
- Jobianne M. LACHAUD
 
### Description de l'aplication
Gérer les données d'un établissement scolaire pendant des années, n'est pas une mince affaire, c'est pourquoi, on ne peut pas vraiment tenu les dirigeants comme responsable
de l'ingérence de ces derniers. Surtout, s'ils sont stocker sur des supports durs tel le papier. C'est pourquoi fort souvent ces derniers sont malnenées voire égarées.
GEES, étant une application de gestion éfficace des données des établissement scolaires, se promet une révolution dans le domaine, elle permet de gérer de manière fluide et
efficace les données des apprenants (élèves), enseignants, personnels adminbistratifs et autres...
En outre, elle garantie l'accès à toutes les données n'importre-où et à n'impotre quelle heure, et en toute sécurité. Elle offre une stockage locale et en ligne.


# User Stories
# Must have
## L'application GEES est destinée aux propriétaire d'école. Ils pourront :
- [X] Enregistrer leur école
- [X] Donner un accès aux membres administratifs, tels, Secretaire, Comptable, Directeur pédagogique et autre de son choix...
- [X] Avoir un aperçu clair de l'évolution de l'établissement vis-à-vis des élèves, enseignants et autre personnels
- [X] Gerer leur agenda et les horaire des classes
- [X] Voir à distance le nombre d'aprenants et de personnels enregister/pointer pour chaque journée de fonctionnement
- [X] Voir l'évolution des personnels enseignants dans leur programme
